Телеграмм-бот для получения данных по температуре, влажности, давлении от подключенного датчика BME280, а также формирования уведомления в случае срабатывания датчика протечки.

<img width="800" height="800" alt="image" src="https://github.com/user-attachments/assets/4c29f86f-b69e-4823-8671-cd0afa413160" />

Сам бот реализован на плате ESP8266, которая постоянно подключена к прописанной в коде точке доступа.
